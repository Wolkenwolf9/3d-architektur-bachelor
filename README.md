#3D Architektur Webapplikation

Dieses Projekt entstand im Rahmen einer Bachelorarbeit im Studiengang Medieninformatik an der Berliner Hochschule für Technik (BHT). Ziel der Arbeit ist die prototypische Entwicklung einer webbasierten Anwendung zur interaktiven Exploration eines Architekturmodells.

Die Anwendung ermöglicht es, ein 3D-Modell des Hochschulgebäudes Haus Bauwesen direkt im Browser zu betrachten und mit verschiedenen Interaktionsmechanismen zu erkunden.

##Technologien

###Frontend:

React
Next.js
Tailwind CSS
3D Rendering:
Three.js
React Three Fiber
GLTF Loader
Draco Compression

###Deployment:

Vercel

##Installation

Repository klonen:

git clone https://github.com/Wolkenwolf9/3d-architektur-bachelor.git

Projektordner öffnen:

cd 3d-architektur-bachelor

Abhängigkeiten installieren:

npm install

Development Server starten:

npm run dev

Die Anwendung läuft dann unter:

http://localhost:3000
